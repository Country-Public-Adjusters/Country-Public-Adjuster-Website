Functionality

Sitewide Features

Feature Description
Navigation Sticky header with dropdown menus. Compresses into a compact pill on scroll. Full-screen mobile menu.
Mobile CTA Bar Fixed bar at the bottom of the screen on mobile — always-visible Call and Get Inspection buttons.
AI Chat Widget Chatbase AI chatbot embedded site-wide. Custom gold button — visitors can ask questions and get instant answers 24/7.
AI Voice Agent Retell AI-powered voice agent handles after-hours calls and intake. Captures lead details via natural conversation and routes them to the team — so no lead is missed outside business hours.
Smooth Scroll Lenis smooth scrolling gives the site a cinematic, premium feel as users navigate.
Custom Cursor Premium dot-and-ring cursor system on desktop. Reacts to interactive elements with a gold highlight.
Analytics Ready Google Tag Manager integration. Tracks CTA clicks, phone clicks, form steps, scroll depth, and more.
SEO Infrastructure Auto-generated sitemap.xml, robots.txt, Open Graph tags, canonical URLs, and JSON-LD schemas on every page.
Performance All 29 pages pre-built as static HTML at deploy time. Near-instant load speeds globally.
Accessibility Skip-to-content link, keyboard focus styles, reduced-motion support for users with motion sensitivities.
Security Security headers on all responses: X-Frame-Options, Content-Type-Options, Referrer-Policy.
